# REELSKING

댄스 챌린지 영상을 따라 하며 Python 모션 인식 라이브러리와 휴리스틱 기반 점수 채점 AI layer로 정확도를 분석하는 웹 서비스입니다. 챌린지 학습, 점수 기록, 영상 공유 흐름을 중심으로 설계했습니다.

## 핵심 구현

- Python 모션 인식 라이브러리 기반 동작 특징 추출
- 휴리스틱 기반 점수 채점 AI layer
- 유튜브·업로드·웹캠 기반 모션 인식 채점 플로우
- 해시태그·유저 검색이 가능한 소셜 피드
- 영상 공유, 좋아요, 댓글, 공유 인터랙션
- 챌린지별 점수 이력 및 통계
- 반복 학습을 돕는 게이미피케이션 모드

## 주요 기능

- 챌린지 선택
- 영상 또는 웹캠 입력
- 모션 분석 및 정확도 점수화
- 개인 점수 히스토리 확인
- 챌린지 영상 공유

## 기술 영역

- Motion Recognition
- Python
- Heuristic Scoring
- Computer Vision
- Video Analysis
- Social Feed UX
- Progress Tracking

## 설계 포인트

정확도 점수만 보여주는 도구보다, 사용자가 같은 챌린지를 반복하면서 실력이 올라가는 흐름을 확인할 수 있는 학습형 소셜 경험에 초점을 맞췄습니다.
